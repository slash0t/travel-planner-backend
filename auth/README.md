# Сервис аутентификации Travel Planner

Сервис управления доступом, регистрации и авторизации пользователей для приложения Travel Planner.

## Основные возможности

- Регистрация пользователей с подтверждением email
- Аутентификация с использованием JWT токенов
- Управление профилем пользователя
- Механизм восстановления пароля
- Защита токенов с использованием подписи JWT

## Технологии

- Java 23
- Spring Boot
- Spring Security
- Spring Data JPA
- JWT (JSON Web Tokens)
- Hibernate

## Конфигурация

Основные настройки находятся в файле `application.yml`. Важные параметры:

- `app.jwt.secret` - секретный ключ для JWT токенов
- `app.jwt.access-token-expiration` - время жизни токена доступа
- `app.jwt.refresh-token-expiration` - время жизни refresh токена
- `spring.mail.*` - настройки почтового сервера для отправки писем

## API Endpoints

### Аутентификация
- `POST /login` - вход в систему
- `POST /refresh` - обновление токена
- `POST /logout` - выход из системы
- `POST /anonymous-token` - получение анонимного токена

### Регистрация
- `POST /register` - регистрация нового пользователя
- `POST /verify-email` - подтверждение email
- `POST /resend-verification` - повторная отправка письма для подтверждения

### Восстановление пароля
- `POST /forgot-password` - запрос на восстановление пароля
- `POST /verify-reset-code` - проверка кода восстановления
- `POST /reset-password` - сброс пароля

### Управление профилем
- `GET /me` - получение информации о текущем пользователе
- `PUT /me` - обновление профиля
- `POST /me/avatar` - загрузка аватара
- `POST /me/change-password` - изменение пароля

## Безопасность

- Все пароли хранятся в хешированном виде с использованием BCrypt
- JWT токены имеют ограниченное время жизни
- Реализована защита от brute-force атак
- Поддержка CORS для безопасного взаимодействия с фронтендом
